# GitHub Pages 上传说明

此文件夹已经是纯预览静态版，不包含作品编辑后台。

1. 把本文件夹内的全部内容上传到 GitHub 仓库根目录。
2. 首页文件必须保持名称为 index.html。
3. 不要删除 media 文件夹、favicon.svg 或 .nojekyll。
4. 如果仓库名为“你的用户名.github.io”，上传后可直接用对应网址访问。

上传完成后，仓库根目录必须能直接看到：

- index.html
- favicon.svg
- media 文件夹
- README-上传说明.md

点开 media 后，还应看到 project-emoji、project-vlink 等 6 个项目文件夹。
如果仓库根目录只有 index.html，而没有 media，网页文字仍会显示，但所有图片会破图、视频会显示 0:00。

使用 GitHub 网页上传时，请把解压后文件夹里的“全部内容”一起拖入上传区域，尤其要包含整个 media 文件夹；不要只选择最外层的几个单独文件。

更新作品时，请回到原可编辑网站修改，再重新导出静态版。
